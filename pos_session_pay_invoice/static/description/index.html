POS Session Pay Invoice

Cobro y pago de facturas desde una sesión de TPV (Odoo 18)

Este módulo permite cobrar y pagar facturas desde una sesión de Punto de Venta (TPV). Para facturas de cliente, el cobro se registra como un pago real del TPV (pos.order + pos.payment) para que quede reflejado en el control de caja y el cierre de sesión.

Configuración

  1. Ir a Punto de Venta → Configuración → Punto de Venta y abrir la configuración del TPV.
  2. En Métodos de pago, asegúrate de que:
    • Existe al menos un método de pago con diario asociado.
    • Para movimientos de caja, al menos un método tiene un diario de tipo cash (efectivo).

Uso

  1. Ir a Punto de Venta → Dashboard y crear/abrir una nueva sesión de TPV.
  2. Desde la sesión, utiliza la acción/botón Pay / Refund invoice.
  3. Selecciona el método de pago (ej. Efectivo) y la factura pendiente.
  4. Confirma: el sistema registra el pago y lo aplica automáticamente a la factura.

Si el TPV tiene múltiples métodos de pago, podrás escoger el método correspondiente en el wizard.

Incidencias conocidas / Roadmap

  • No se pueden gestionar pagos si no existe un diario de caja asociado al método de pago seleccionado.
  • Mejora prevista: crear/usar automáticamente el journal asociado al método de pago para el cobro/pago.
