Account Cash Invoice

Pagar y cobrar facturas desde extractos / diarios de Caja y Banco

Este módulo añade un asistente para registrar pagos de facturas directamente desde extractos bancarios o diarios de caja, creando líneas de extracto y realizando la conciliación automática con la factura seleccionada.

Funciones principales

  • Asistente para pagar/cobrar facturas desde un diario de tipo bank o cash.
  • Crea una línea de extracto (account.bank.statement.line) vinculada a la factura.
  • Conciliación automática de las partidas a cobrar/pagar contra el movimiento generado.
  • Acceso rápido desde el dashboard del diario (opción “Pay Invoice”).

Cómo se usa

  1. Ir a Contabilidad → Tablero.
  2. Abrir un diario de tipo Caja o Banco.
  3. En el menú de acciones del diario, seleccionar Pay Invoice.
  4. Elegir el tipo (Cliente / Proveedor), la factura y el importe.
  5. Confirmar: se crea la línea de extracto y se concilia con la factura.

Requisitos / Configuración

  • Debe existir al menos un diario de tipo cash o bank.
  • Las facturas deben estar publicadas y no pagadas.
  • El usuario debe tener permisos sobre Contabilidad y extractos.

Créditos

  • Creu Blanca
  • Tecnativa
  • Servincom Soluciones (ajustes y adaptación interna)
