Installation
============

To install this module, you need to:

#. Install the required Python dependencies:

   .. code-block:: bash

      pip install asterisk-ami phonenumbers

#. Copy the module to your Odoo addons directory
#. Update the app list in Odoo
#. Install the "Asterisk Pro Connect" module

Configuration
=============

#. Go to **Settings > Technical > Asterisk Pro Connect > Servers**
#. Create a new Asterisk server configuration:
   
   * **Name**: Friendly name for your server
   * **Host**: Asterisk server IP or hostname
   * **Port**: AMI port (default: 5038)
   * **Username**: AMI username
   * **Password**: AMI password

#. Configure user extensions in **Settings > Users > [User] > Asterisk Configuration**
#. Test the connection using the "Test Connection" button
#. Start making calls!

Usage
=====

Click-to-Call
-------------

* Open any contact or opportunity record
* Click the phone icon next to phone numbers
* The call will be initiated through your configured extension

Call Dashboard
--------------

* Access your personal call dashboard from the main menu
* View call statistics, recent calls, and quick actions
* Monitor your call performance and activity

Call Notifications
------------------

* Receive real-time notifications for incoming calls
* View caller information and call history
* Accept, reject, or transfer calls directly from notifications

CRM Integration
---------------

* Calls are automatically linked to contacts and opportunities
* Create new opportunities directly from call records
* Track call outcomes and follow-up activities
